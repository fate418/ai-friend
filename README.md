## 📖 项目概述

心有灵犀智能伴侣是一款基于Streamlit框架和大语言模型开发的AI伴侣应用。它能够以温柔贴心的口吻与用户进行自然对话，成为用户的倾听者和开导者，帮助用户缓解压力、分享心情。当孤独成为一种常态时，心有灵犀智能伴侣能够提供情感支持和建议，帮助用户保持情感健康。

### 核心功能与特点

- **智能对话**：基于llM，提供流畅自然的对话体验
- **个性化定制**：支持自定义伴侣昵称和性格特征
- **对话历史**：自动保存对话记录，支持查看和管理历史对话
- **实时响应**：采用流式输出，实时显示AI回复内容
- **界面友好**：简洁美观的Streamlit界面，操作便捷

## 🚀 安装与使用指南

### 环境要求

- Python 3.8 或更高版本
- 稳定的网络连接（用于调用llM API）

### 依赖项

```
streamlit
openai
python-dotenv
```

### 安装步骤

1. **克隆项目**
```bash
git clone https://github.com/fate418/ai-friend.git
cd ai-friend
```

2. **安装依赖**
```bash
pip install -r requirements.txt
```

3. **配置API密钥**

复制 `.env.example` 文件为 `.env`，并填入您的API配置：
```bash
cp .env.example .env
```

编辑 `.env` 文件，填入您的API Key：
```env
# API Key (必填)
API_KEY=your-api-key-here

# Base URL (选填，默认为 https://api.deepseek.com)
BASE_URL=https://api.deepseek.com

# Model Name (选填，默认为 deepseek-chat)
MODEL_NAME=deepseek-chat
```

4. **启动应用**
```bash
streamlit run heart_ai.py
```

5. **访问应用**

启动后，在浏览器中访问 `http://localhost:8501`

### 基本使用流程

1. 配置 `.env` 文件中的API Key
2. 启动应用，设置伴侣的昵称和性格
3. 在底部输入框输入你想说的话
4. AI伴侣会以温柔的语气回复你
5. 对话会自动保存，可以随时查看历史对话
6. 点击"新建对话"开始新的聊天

## ❓ 常见问题与故障排除

### 1. API密钥错误

**问题提示：** `AuthenticationError` 或 `Invalid API Key`

**解决方案：**
- 确认已创建 `.env` 文件并正确配置 `API_KEY`
- 检查API密钥是否有效且未过期
- 确认API密钥没有多余的空格或引号
- 检查 `BASE_URL` 是否正确

### 2. 对话保存失败

**问题提示：** 无法保存对话记录

**解决方案：**
- 检查程序是否有文件写入权限
- 确认 `sessions/` 文件夹存在且可写
- 检查磁盘空间是否充足

### 3. 页面无法访问

**问题提示：** 浏览器无法打开 `http://localhost:8501`

**解决方案：**
- 确认Streamlit服务已成功启动
- 检查端口8501是否被其他程序占用
- 尝试使用其他端口：`streamlit run heart_ai.py --server.port 8502`

### 4. AI回复缓慢

**问题：** AI响应时间过长

**解决方案：**
- 检查网络连接是否稳定
- 确认DeepSeek API服务状态正常
- 尝试减少对话历史长度

### 5. 中文显示乱码

**问题：** 对话内容显示为乱码

**解决方案：**
- 确保系统支持UTF-8编码
- 检查浏览器编码设置为UTF-8
